# 이 하네스를 쓰면 무슨 일이 일어나나

이 문서는 **사용자 관점**만 다룬다. 어디서 답을 해야 하는지, 어디가 자동인지, 막혔을 때 무엇을 하는지.

단계별로 에이전트가 무엇을 하는지는 `skills/run/SKILL.md`, 설치·저장소 설정은 `README.md`가 정본이다. 여기서 되풀이하지 않는다.

메인 에이전트는 이 문서를 사용자에게 **설명하는 데만** 쓴다. 이 skill이 불렸다고 spec을 만들거나 실행을 시작하지 않는다.

---

## 한 줄 요약

**코드를 바로 짜지 않는다.** 무엇을 왜 만들지 먼저 확정하고, 그 확정된 명세가 구현을 끌고 간다.

## 크게 세 구간

```
🧠 명세 확정          🔧 변환·검증        🤖 실행
사람이 주도            기계가 옮기고 대조    기계가 구현
며칠 걸려도 됨          몇 분                한 번에 완주
질문이 많이 온다        확인만               중간에 두 번 멈춘다
```

- **명세**가 끝나면 요구와 계약이 **동결**된다. 그 뒤로는 읽기만 하고, 바꾸려면 이 구간으로 되돌아온다.
- **변환·검증**은 다시 만들어도 되는 산출물이라 부담 없이 재작성한다.
- **실행**은 시작하면 여러 step을 자동으로 돈다. 사람은 결과를 본다.

## 언제 내가 답해야 하나

에이전트가 멈추고 기다리는 지점이다. **답하지 않으면 넘어가지 않는다.**

| 시점 | 무엇을 묻나 |
| --- | --- |
| 초반 인터뷰 | 목표·제약·완료 기준. 모호한 것을 좁힌다 |
| 모호함 해소 | 결정되지 않은 것들. **위험영역은 끝까지 묻는다** |
| 설계 마친 뒤 | "이제 동결된다. 진행할까?" |
| 정합성 검사 뒤 | 발견 항목을 하나씩 — 고칠지, 근거를 적어 반려할지 |
| 실행 직전 | "정말 구현을 시작할까?" + 에이전트별 모델 |
| PR 리뷰 뒤 | "리뷰 다 끝났나?" — 코멘트가 없다는 것은 완료가 아니다 |

**위험영역**은 틀리면 데이터·돈·접근권한이 깨지는 곳이다(결제·인증·데이터 모델·상태 전이). 여기가 미확정이면 "적당히 알아서" 가 통하지 않는다. 질문 수 제한도 면제되어 끝까지 묻는다.

## 무엇이 자동인가

실행 구간이다. 한 step마다 이 다섯이 돈다.

```
구현 → 검증 명령 실행 → 검토 → 커밋 → 기록
```

step 하나가 커밋 하나다. 실패하면 같은 step을 최대 3회까지 다시 돌고, 3회 안에 안 되면 멈춰서 보고한다. 진행은 `/workflows`로 볼 수 있다.

## 무엇이 나를 막나

게이트는 조건을 만족하지 못하면 다음으로 넘어가지 않는 지점이다. 만났을 때 할 일은 대개 정해져 있다.

| 막혔다는 신호 | 무엇을 하면 되나 |
| --- | --- |
| 위험영역 마커가 남아 있다 | 그 질문에 답한다. 미루기가 안 되는 항목이다 |
| 확인 방법이 없는 요구가 있다 | "이게 됐다는 걸 무엇으로 아나"를 정한다 |
| 정합성 검사에 치명 항목이 있다 | 고치거나, **근거를 적어** 반려한다. 근거 없는 반려는 통과하지 않는다 |
| 검증 명령 형식이 어긋났다 | 해당 step 문서를 고친다 |
| 분석이 낡았다 | 문서를 고친 뒤 검사를 다시 돌린다 |
| step이 3회 실패했다 | 원인을 고치고 그 step을 다시 열어 준다 |

"고치겠다"고 표시하는 것만으로는 치명 항목이 풀리지 않는다. **다시 검사해서 그 발견이 사라져야** 통과한다.

## 한 세션에 다 끝내지 않아도 된다

명세 구간은 며칠에 걸쳐 오갈 수 있다. 진행 상태가 파일로 남아, 다음에 이어서 하면 **끝나지 않은 첫 단계부터** 재개한다.

되돌아가는 것도 정상이다.

- 시나리오를 쓰다 "이 경우엔 어떻게 되지?"가 나오면 → 모호함 해소로 돌아간다
- 설계하다 경합·복구 상황이 드러나면 → 시나리오를 보강한다

되돌아가면 그 뒤 단계를 다시 확인해야 한다는 것만 알아 두면 된다.

## 끝나면 무엇이 남나

- **코드와 커밋** — step 단위로 나뉘어 있다
- **PR** — 초안 상태로 열린다. 루트 문서 반영이 끝나야 초안이 풀린다
- **명세 아카이브** — 작업 폴더는 사라지지만 정본은 복사되어 커밋에 남는다
- **갱신된 루트 문서** — 계약·스키마·구조가 바뀌었으면 반영된다

머지는 **사람이** 한다. 에이전트는 머지하지 않는다.

## 시작하려면

```
/spec-harness:run
```

"이걸 만들고 싶다"고 말하면 인터뷰부터 시작한다.
