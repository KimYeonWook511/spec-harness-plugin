# Freeze(동결)

기능 spec에 버전 태그를 붙인다. 태그 이후 구현 저장소는 이 버전을 입력으로 삼는다.

1. **버전을 정한다.** 첫 동결은 `F<번호>-v1`, 이후는 `SKILL.md`의 버전 규칙을 따른다. `freeze`가 이 규칙으로 막는다.
2. **CHANGELOG.md에 항목을 쓴다.**

   ```markdown
   ## F01-v1.1 (YYYY-MM-DD)
   - 바뀐 것:
   - 왜:              (버그에서 시작했으면 그 버그)
   - 기존 구현에서 고칠 것: <플랫폼별, 없으면 없음>
   ```

3. **기능 목록을 갱신한다.** `<FEATURE_ROOT>/index.md`에서 이 기능의 최신 버전과 상태를 바꾼다.
4. **확인한다.**

   ```bash
   python3 "<EXEC>" freeze <F> --version F01-v1
   ```

   통과하면 Freeze가 `in_progress`가 된다.
5. **동결을 알리고 진행을 확인받는다.** 이후 요구·불변 시나리오·계약을 바꾸면 버전이 올라가고 구현 저장소가 다시 확인해야 한다는 것을 알린다. 사용자가 답해야 넘어간다.
6. **PR을 올리고 머지한다.** 저장소의 PR 규칙을 따른다. 머지는 사람이 한다.
7. **머지된 체크아웃에서 태그를 찍는다.**

   ```bash
   python3 "<EXEC>" freeze <F> --version F01-v1 --tag
   ```

   커밋되지 않은 변경이 있으면 찍지 않는다. 태그 push는 사용자 확인을 받고 한다(`git push origin F01-v1`). 구현 저장소의 다른 사람이 이 버전을 읽으려면 원격에 있어야 한다.
